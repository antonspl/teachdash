## Clarifications

Decisions by the engineer:

1. Space mapping by role, not by value. Today's `--space-1` to `--space-4` (0.5, 1, 1.5 and 2.5rem) are removed and each use is mapped by role: inside a box or a row `--space-group`; between sibling blocks and fields `--space-block`; label to field `--space-adjacent`; icon and word, and chips `--space-inline`; an input row `--space-button-gap`; between sections `--space-section`; Page padding `--space-block` by `--space-group` when narrow and `--space-page` from 40rem. `design.md` lists each use (file:line to new token). Screens visibly tighten; accepted.
2. `AppHeader` loses `--shadow-card`. It gets `border-bottom: var(--border-width) solid var(--color-divider)` instead (white on the new page background is 1.07:1, so the header needs an edge).
3. The Dialog edge (`Dialog.module.css:7`) becomes `--color-divider` now (a "card edge" per the rename map). The Dialog's no-border, `--shadow-overlay`, `--color-backdrop` and width stay in step 3b (#198).
4. Headings get `font-weight: var(--weight-strong)` (600) in Title, Section heading and Dialog title (the user-agent bold is 700 today). The Dialog title and the Section h2 use `--text-large` and `--line-height-large`; Title keeps `--line-height-tight`.
5. Select chevron: the inline 12-unit SVG in `Select.tsx` is replaced by `ChevDownIcon` (`frontend/src/ui/icons.tsx`) at the default `--icon-size`, colour `--color-text-muted`. Box-level inset: the icon box sits `--space-group` from the inner right edge (the span has `right: calc(var(--border-width) + var(--space-group))`), `pointer-events: none`, `data-select-arrow` kept, `appearance: none` kept. Text clearance: `padding-right: calc(var(--space-group) + var(--icon-size) + var(--space-inline))`. `web-client` R13 and `e2e/selectArrow.spec.ts` stay unchanged (the left padding must stay equal to the arrow gap, R13-S1). `--arrow-width` is removed. R13's redefinition stays in #197.
6. `text-wrap: balance` and `pretty` and `tabular-nums` are NOT added in this change (left to 3a #197 and 3b #198).
7. Stale references in the vendored docs under `.agents/design` (`refactoring-ui*.md`, `accessibility*.md` and any other file naming `--shadow-card`, `--color-border`, `--space-1` to `--space-4`, the success variant or `--arrow-width`) are updated to the new token names in this PR, in a separate commit. ## Research angles and conclusions

Angles: the token usage and the rename map in the code, the specs and tests affected, contrast, and the visual plan (`frontend-researcher`).

- Only the `web-client` spec is affected. No spec names the success variant, shadows, border colours or the removed tokens. R22 (icon size tokens) is unchanged (same values). R13 is unchanged (Clarification 5), except R13-S2 (Clarification 19). The new requirements are added to `web-client` after R23.
- Existing tests find buttons by role and name and read no computed shadows or colours, so no approved test should change. Layout-sensitive e2e to re-run at 360 in en and ru: R7-S1, R13-S2, `skeleton.spec.ts` and `russianFit.spec.ts` (R15-S6). Title drops from 2rem to 1.5rem, controls from 44 to 40px at `pointer: fine`, and button padding from 24 to 12px.
- Usage facts: `--arrow-width` is used only at `Field.module.css:44,65,66`. The success variant is at `Button.tsx:17` and `Button.module.css:33-41`, used at `AdminTeachersPage.tsx:299,460`. `--shadow-card` is at `List:15`, `StatusMessage:5`, `AppHeader:9` and `IssuedLink:10`. `--color-border` as a control edge is at `Field:30,85`, `Button:24` and `IssuedLink:26` (to `--color-control-border`); as an edge it is at `List:13`, `IssuedLink:8` and `Dialog:7` (to `--color-divider`). `Button:29-30` danger fill uses `--color-danger-text` (to `--color-danger-action`). `Field:70` error border keeps `--color-danger-text`. Five raw `font-weight: 600` become `--weight-strong`. `var(--space-[1-4])` has 38 uses in 22 CSS files.
- Contrast (design-code values, light only): control-border 4.13 on surface, 3.86 on background, 3.59 on sunken, 3.39 on rail, 3.37 on accent-subtle and neutral background, 3.49 on success background, 3.40 on danger background. Divider is 1.39 on surface. The old `#9aa5b1` is 2.50 on white and 2.36 on `#f7f8fa`. Text pairs are at least 5.7; on-accent on accent 7.99; on-accent on danger-action 7.10.

## What changes

- `frontend/src/styles/tokens.css` holds exactly the design-code token tables (colour, type, space, shape and motion, controls and icons, layout), with new names and changed values. The rename map is applied across all `src/ui` CSS, with no aliases (`design.md` D2, D3).
- Button: the `success` variant is removed; "Add teacher" and "Create teacher" are the accent primary; the danger fill is `--color-danger-action`.
- Shadows are removed from List item, StatusMessage, AppHeader (a divider bottom border instead) and IssuedLink. The select chevron is `ChevDownIcon`.
- `check-design-tokens.mjs` also fails on undefined `var(--name)`.
- Vendored design docs get the new token names, in a separate commit.
- `web-client` gets R24 (design tokens), R25 (no removed or undefined token), R26 (control and text contrast, closes #168), R27 (Button roles) and R28 (no card shadows, shared select chevron).
- Tests: Vitest on `tokens.css` and the CSS as text, a Vitest of the lint script, page and component tests, one Playwright check of the chevron size. Before and after screenshots of every page state.

## Out of scope

- The redefinition of R13's arrow gap (#197); dark mode; backend changes; new dependencies; Flyway migrations.
